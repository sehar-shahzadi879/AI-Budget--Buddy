# 💰 AI Budget Buddy

AI Budget Buddy is a simple and smart web application that helps users manage their daily expenses, control their budget, and improve their savings.

## 🚀 Live Demo

https://sehar-shahzadi879.github.io/

## 🎯 Problem

Many people find it difficult to track daily spending and stay within their monthly or daily budget.

AI Budget Buddy provides a simple way to record expenses, monitor spending, and receive smart budget suggestions.

## 💡 Solution

The app allows users to:

- Set a budget
- Add daily expenses
- Organize expenses by category
- See total spending
- Check remaining budget
- Get smart budget alerts
- Set a savings goal
- Receive saving suggestions
- View expenses in a chart
- Delete individual expenses
- Reset all data

## 🤖 AI-Based Features

The app provides smart, rule-based recommendations based on the user's spending and remaining budget.

Examples:

- ✅ On-track spending alert
- ⚠️ Warning when spending reaches 80% of the budget
- 🚨 Alert when the budget is exceeded
- 💡 Smart saving suggestions
- 🎯 Savings goal feedback

## 📊 Main Features

### Budget Management
Users can set a budget and monitor how much they have spent and how much remains.

### Expense Tracking
Users can enter an amount and category such as Food, Travel, or Books.

### Smart Budget Alert
The application automatically checks spending percentage and provides an appropriate alert.

### Savings Goal
Users can set a savings target and receive feedback based on their remaining budget.

### Expense Chart
A doughnut chart visually represents spending by category.

### Data Persistence
Expense and budget information is stored in browser Local Storage so it remains available after refreshing the page.
